# What Is This?
A Hough Line detector implemented in Python, using Matplot, Numpy, and OpenCV libraries. Finds probable lines in input images and outputs an image with those lines drawn on top. For comparison, lines from the OpenCV method HoughLinesP are drawn on the image as well.

# How Do I Use This?
Place images in the Data folder and run houghScript.py. The parameters can be tweaked to improve individual image performance. Intermediate images and predicted line images will be outputted in the results folder.
